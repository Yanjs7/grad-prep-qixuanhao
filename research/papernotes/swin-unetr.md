# Swin UNETR 阅读笔记

**论文名称**：Self-Supervised Pre-Training of Swin Transformers for 3D Medical Image Analysis

[论文原文](../papers/Swin.pdf) · [返回论文列表](../README.md#2-论文列表与阅读记录)

模型叫 **Swin UNETR**。

它与 [DTC](dtc.md)、[BCP](bcp.md) 的主要区别是**使用无标注影像的时机**：DTC、BCP 在分割训练时同时使用有标注和无标注影像；这篇先用大量无标注 CT **预训练**模型，再用有分割标注的影像**微调**它。

```
5050 份 CT（预训练时不用器官标签）
       ↓ 学习影像特征
少量有标注的三维影像
       ↓ 学习具体要分割哪个器官
三维分割结果
```

## 没有标签，预训练学什么？

作者给模型布置了三道“答案能从影像本身得到”的题，因此不需要医生画分割轮廓：

1. **遮住再补全**：遮住 CT 体块的一部分，让模型根据周围内容还原它。可以理解成三维版的“完形填空”。
2. **判断旋转角度**：把体块旋转后，让模型判断转了多少度。模型需要留意影像的空间结构。
3. **对比学习**：同一个体块经过两种处理后，模型应认出它们来自同一处；不同体块则要能区分。

这三道题训练的是模型读取三维影像的能力，**还没有教它“哪些体素是胰腺”**。到了微调阶段，作者保留预训练得到的编码器，接上分割网络，用真实器官标签完成这一步。
