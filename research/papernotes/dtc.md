# DTC 阅读笔记

**论文名称**：Semi-supervised Medical Image Segmentation through Dual-task Consistency

[论文原文](../papers/DTC.pdf) · [返回论文列表](../README.md#2-论文列表与阅读记录)

输入同一份三维 CT，网络会同时给出两种结果：

1. **直接分割**：判断每个体素属于器官的概率，例如“这里有 80% 的可能是胰腺”。
2. **描述边界**：预测每个体素与器官边界的关系；再把这个结果转换成一张分割概率图。

两条分支看的是**同一份影像、同一个器官**，所以转换后的分割图应该接近直接分割图。论文把“让两张图接近”称为**双任务一致性**。

```
一份三维影像
    ├─ 分支 A：直接预测器官分割图 ────────┐
    └─ 分支 B：预测边界 → 转成分割图 ────┤
                                      比较两张图，缩小差异
```

## 没有标签时，模型怎么学？

**有标注的影像**：医生画出的真实分割图可以指导两个分支；两个分支还要彼此保持一致。

**没有标注的影像**：虽然无法知道哪张预测图是正确答案，仍然可以检查它们是否矛盾。例如，同一个位置，分支 A 预测为器官的概率是 0.8，分支 B 转换后的概率是 0.4，模型就会受到“让两种预测更一致”的训练信号。这就是它利用未标注数据的关键。

这里有个重要限制：**一致不等于正确**。如果两条分支一起预测错了，一致性本身发现不了。因此，少量真实标注仍负责告诉模型“正确的器官长什么样”；未标注影像提供额外的一致性约束。

少量真实标注负责校准答案，大量未标注三维影像则通过“直接分割”和“边界推得的分割”相互核对来参与训练。
