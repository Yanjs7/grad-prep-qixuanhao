# Gastric-X 阅读笔记

[论文原文（CVPR正式版）](../papers/gastric-x.pdf) · [返回论文列表](../README.md#2-论文列表与阅读记录)

## 1. 基本信息与总结

- **题目**：Gastric-X: A Multimodal Multi-Phase Benchmark Dataset for Advancing Vision-Language Models in Gastric Cancer Analysis
- **作者**：Yuanzhe Li、Hao Chen、Rui Yin、Juyan Ba、Yu Zhang、Sheng Lu，以 CVF 正式版顺序为准。
- **发表**：CVPR 2026，pp. 2490–2501。
- **总结**：把胃癌患者的多期CT、胃镜、检验、报告和空间标注按患者关联起来，建立五项任务，评估现有视觉语言模型利用这些信息的能力。

**论文主要贡献是数据集与评测基准。它没有提供少标签比例实验，也没有直接证明仅平扫CT的诊断能力。**

## 2. 数据包含什么

| 数据或标注 | 论文报告的内容 | 阅读时的区分 |
|---|---|---|
| 多期CT | 平扫、动脉期、静脉期、平衡/延迟期；约7.1K扫描 | 多期属于同一影像模态的不同采集期相 |
| 胃镜 | 约1.7K图像 | 与CT互补的另一种影像来源 |
| 检验与EHR | 11项血清生化、5项肿瘤标志物；总计134项结构化字段 | 134项还含人口学、手术、病理及术后信息，不能全称血液指标，也不能默认全部作为输入 |
| 报告 | CT描述、胃镜报告、诊断总结 | 在不同任务中可作为监督目标或检索文本，不能默认都是诊断输入 |
| 空间与分期标注 | 21,408个3D框，涉及肿瘤、区域淋巴结、胃区域；TNM及总体分期 | 框是专家先验；不是独立生理模态，也不等于像素级分割 |
| 问答 | 26,760组VQA | 来自临床报告，经LLM生成候选、两名临床专家对照报告核验 |

论文总体规模约1.7K病例，正文另写1.74K患者。这些都是论文报告值；不把近似统计代替实际发布清单。

## 3. 多模态具体怎样实现

### 影像分支

对部分2D模型，将不同期相CT切片拼成多通道表示；对X²-VLM，将视觉编码器换为3D Swin Transformer、文本编码器换为MedBERT，得到X²-VLM-Med。各基线适配方式不同。

### 表格分支

提取超出正常阈值的检验项，写成“项目名＋测量值＋超过正常上限的倍数”的简短文本，再接入VLM。**主要实验没有把表格统一设计成独立MLP编码器。**

### 空间提示

把BBox画成彩色框叠加到CT切片，提示模型关注区域。它相当于额外提供专家定位；实际部署必须说明这些框由谁产生。

### 四组输入对照

1. Image Only：影像。
2. Image + Table：影像＋检验文本。
3. Image + BBox：影像＋定位框提示。
4. Image + Table + BBox：三者组合。

**Image Only不等于NCCT Only。** 数据集虽含胃镜，主要输入消融并未单独展示“CT＋胃镜”的增益，不能说全部模态在所有任务中均同时融合。正文对各模型的连接与训练细节也不足以直接复现统一网络。
