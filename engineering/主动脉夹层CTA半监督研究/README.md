# 第三项实践：主动脉夹层CTA半监督研究

[返回工程总览](../README.md) · [返回仓库首页](../../readme.md)

![CTA数据集来源与标签组成](figures/07_dataset_distribution.png)

### 真实CTA图像与模型输入

![AortaSeg Dissec_06真实CTA及预测主动脉ROI](figures/dissec06_roi.png)

**怎么看这张图：** 左侧是冠状面和矢状面，其他小图是多个轴位采样位置；黄色为自动预测的主动脉ROI，用于确定输入区域。它没有标注夹层病灶，也不能代表完整病灶覆盖。此例来源标签为阳性，但三个阶段均漏判，说明定位结果与分类结果需要分别评价。

![Old_03模型输入块的中心层](figures/old03_patch.png)

**模型实际看什么：** 这是Old_03的15个输入块中心层，其中12个为名义块、3个为补充块。每个三维块尺寸为32×96×96，图中只展示其中心一层；模型对整块编码，再用注意力MIL聚合扫描分数。Old_03属于来源支持的阴性候选，后续分类变化见下表。

这些图像来自已归档的输入技术预览。归一化显示和黄色ROI用于核对输入，不能作为医生诊断或夹层病灶真值；原预览中的`coverage pending`也不表示后来完成了临床覆盖认证。

### 代表案例解析

| 案例与来源标签 | S1分数 / 本折阈值 | S1表现 | 对照解读 |
| --- | ---: | --- | --- |
| Dissec_02：来源阳性 | 0.666825 / 0.514373 | 正确识别（TP） | 三组均正确，单例不能代表所有阳性 |
| Dissec_06：来源阳性 | 0.409013 / 0.440865 | 漏判（FN） | 三组均漏判，预测ROI存在不保证识别正确 |
| Old_03：阴性候选 | 0.497256 / 0.514373 | 正确排除（TN） | S0+误判为阳性，S1纠正；不同阶段需使用各自验证阈值 |
| Old_02：阴性候选 | 0.952385 / 0.007967 | 误判（FP） | 三组均误判，仍需检查局部聚合、来源偏差和标签依据 |

分数不是校准后的患病概率；表内为四舍五入展示，原始预测依据完整精度分数和阈值。四例是结果后的描述性选择。Old_03的纠正使AortaSeg特异度从15/19变为16/19，但主比较AUROC差异区间仍跨0，不能据此宣称半监督整体有效。

## 实验规模与结论

| 项目 | 已完成内容 |
| --- | --- |
| 纳入队列 | 712份扫描：224来源阳性、19阴性候选、469诊断未知 |
| 实验 | 固定5折，15个训练阶段、15个固定评估阶段，7000次监督优化步骤 |
| 对照 | S0每折600步；S0+与S1共享验证最佳S0父状态，分别400步 |
| 主分析 | 同来源AortaSeg 29份OOF扫描：10阳性、19阴性候选 |
| 主指标 | S0 / S0+ / S1 AUROC：0.6737 / 0.7316 / 0.7263 |
| 主比较 | S1−S0+ = −0.0053，条件配对95%区间[−0.0737, 0.0632] |
| 结论 | 本固定协议未得到明确半监督改善证据，亦未证明两组等效 |

## 文件组织与复核方法

```text
主动脉夹层CTA半监督研究/
├── README.md
├── 项目实验报告.md
├── figures/                 # 实验图、真实输入预览与案例图
├── results/                 # 原始交付CSV/JSON、冻结协议、运行证据和代码
│   ├── code/cta_ssl/        # 模型、数据、训练与精度等核心实现
│   ├── protocol/           # 冻结配置、数据清单和划分
│   └── evidence/           # 逐折共享父状态与阶段完成记录
├── derived-results.json    # 根据冻结结果计算的描述性汇总
└── 文件清单.json            # 本目录文件大小和SHA-256
```

阅读时先核对 `metrics.csv` 的 AortaSeg 行，再对照配对比较和逐折指标。训练记录应为7000行，OOF记录应为三阶段×243扫描=729行；同一阶段对每份有标签扫描仅有一次折外预测。主分析区间条件于固定预测，不能覆盖重新训练或未知患者重叠的不确定性。

本目录提供实验结果复核所需材料，未包含原始CT、NPZ缓存或模型权重。重新训练还需按原协议准备数据、MASS实现及预训练权重、依赖环境，并迁移配置和冻结脚本中的原服务器路径。代码作为实际实验的冻结快照保留，不能直接将原服务器命令当作本机启动命令；本次整理没有重新启动训练。
