## 当前进度

现有材料支持模型训练和 HTML 结果报告，但尚无独立 Web、桌面或嵌入式项目完成的证据。本节为实施方案，不作为工程任务已完成的声明。`src/` 待补入真实代码，运行截图待实际运行后采集。

## 项目目标与计划功能

面向学习展示，提供图像上传、模型推理、原图与预测对照及结果下载。若上传对应标注，可计算并展示 Dice、IoU 等指标。页面展示输入尺寸与评价条件，避免结果含义不清。

## 拟用技术栈

Python、PyTorch、Streamlit、Pillow、NumPy。复用已验证的 U-Net 网络、预处理与权重加载逻辑；依赖版本待实际实现后固定。

## 实施顺序与验收

1. 整理推理模块，核对权重对应的网络结构、类别映射和预处理。
2. 实现上传、推理与并排展示，处理非图像文件和无效输入。
3. 加入结果下载，记录推理设备和耗时。
4. 实测启动与完整操作流程，将安装和启动命令补入本页。
5. 将入口、预测展示与结果下载截图放入 `screenshots/` 并引用。
